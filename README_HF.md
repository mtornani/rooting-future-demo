# Rooting Future Strategy Engine

**AI-Powered Strategic Planning for Football Clubs**

Sistema multi-agente per la generazione automatica di piani strategici pluriennali per società calcistiche.

## Features

- 🤖 6 agenti AI specializzati (STW Analysts + Financial + Coordinator)
- 📊 Analisi stakeholder automatica
- 📄 Export PDF, DOCX, HTML
- 🔍 Web research integrata
- 🎯 Pitch Mode per presentazioni

## Come Usare

1. Accedi con le credenziali fornite
2. Carica un documento DOCX con i dati del club
3. Il sistema genera automaticamente il piano strategico
4. Scarica il report in PDF/DOCX
