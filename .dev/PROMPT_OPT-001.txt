# PROMPT PER GEMINI CLI - OPT-001: SQLite Indexing

Ciao Gemini! Lavoro su Rooting Future, un sistema AI per generare piani strategici per società calcistiche.

## CONTEXT

Il sistema usa SQLite come database per memorizzare piani strategici.
Attualmente le query sono lente perché non ci sono indici.

**Problema**: Quando cerchiamo piani per categoria o data, il database scansiona tutti i 200+ record uno per uno (scan lineare = lento).

**Soluzione**: Aggiungere indici per velocizzare le query del 70%.

## TECH STACK

- Python 3.11+
- SQLite 3 (database in knowledge_base/rooting_future.db)
- File da modificare: knowledge_store.py

## TASK: OPT-001 - SQLite Indexing & WAL Mode

### Modifiche Richieste

Nel file `knowledge_store.py`, dentro il metodo `_init_db()` (cerca questa funzione):

1. **Aggiungi index su documents table**:
   ```sql
   CREATE INDEX IF NOT EXISTS idx_documents_category_section
   ON documents(category, section_type)
   ```

2. **Aggiungi index su plans table**:
   ```sql
   CREATE INDEX IF NOT EXISTS idx_plans_created
   ON plans(created_at DESC)
   ```

3. **Abilita WAL mode** (Write-Ahead Logging per concurrent access):
   ```sql
   PRAGMA journal_mode=WAL
   ```

4. **Ottimizza performance**:
   ```sql
   PRAGMA synchronous=NORMAL
   ```

### Dove Inserire il Codice

Cerca nel file `knowledge_store.py` il metodo `_init_db()`.
Dopo le istruzioni `CREATE TABLE`, aggiungi gli indici.

**Esempio**:
```python
def _init_db(self):
    cursor = self.conn.cursor()

    # Existing CREATE TABLE statements...
    cursor.execute('''CREATE TABLE IF NOT EXISTS documents ...''')
    cursor.execute('''CREATE TABLE IF NOT EXISTS plans ...''')

    # ⬇️ AGGIUNGI QUI GLI INDICI (dopo le CREATE TABLE)
    cursor.execute('''CREATE INDEX IF NOT EXISTS idx_documents_category_section
                      ON documents(category, section_type)''')
    cursor.execute('''CREATE INDEX IF NOT EXISTS idx_plans_created
                      ON plans(created_at DESC)''')

    # ⬇️ AGGIUNGI QUI I PRAGMA
    cursor.execute('PRAGMA journal_mode=WAL')
    cursor.execute('PRAGMA synchronous=NORMAL')

    self.conn.commit()
```

## REGOLE IMPORTANTI
