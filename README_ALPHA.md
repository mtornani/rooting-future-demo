# Rooting Future Strategy Engine - Alpha v6.0.0

## Quick Start

1. **Run the application:**
   - Double-click `RootingFuture_Alpha.exe`
   - Your browser will open to `http://localhost:5000`

2. **Activation (first time):**
   - Copy your **Machine Code (HWID)** shown on screen
   - Send it to your referent to receive a license key
   - Enter your email and license key to activate

3. **AI Setup (choose one):**

   **Option A - Google Gemini (recommended):**
   - Go to Settings
   - Select "Google Gemini" as provider
   - Enter your Gemini API Key (free at https://aistudio.google.com/apikey)

   **Option B - OpenRouter (alternative):**
   - Go to Settings
   - Select "OpenRouter" as provider
   - Create free account at https://openrouter.ai/keys
   - Enter your OpenRouter API Key
   - Select a free model (Gemini Flash, DeepSeek V3, Llama 4, etc.)

4. **Generate your first plan:**
   - Click "New Plan"
   - Enter club name, city, and category
   - Click "Generate Strategic Plan"
   - Wait 1-2 minutes for AI generation
   - View interactive webapp or download PDF/DOCX

## Features

- Multi-agent AI strategic plan generation
- 6 specialized AI agents (Sporting, Structural, Marketing, Social, Financial, Coordinator)
- Dual AI provider support: Google Gemini or OpenRouter
- Free AI models available via OpenRouter
- Scientific data points with benchmarks
- Interactive webapp viewer with search and navigation
- Export to PDF, DOCX, HTML, OnePager
- Public sharing with password protection
- Real-time progress tracking
- Mobile-responsive interface

## System Requirements

- Windows 10/11 (64-bit)
- 4 GB RAM minimum
- Internet connection required
- AI API key (Gemini or OpenRouter - free tier available)

## Known Limitations (Alpha)

- PDF generation requires Playwright/Chromium (auto-installed)
- Some special characters may cause issues
- Maximum 10 competitors per plan
- File uploads limited to 10 MB

## Troubleshooting

**App doesn't start:**
- Run from Command Prompt to see error messages
- Check Windows Defender hasn't blocked it

**"API key missing" error:**
- Go to Settings and configure your AI provider
- For Gemini: Get free key at https://aistudio.google.com/apikey
- For OpenRouter: Get free key at https://openrouter.ai/keys

**PDF generation fails:**
- Ensure internet connection
- Try DOCX export instead
- Check logs folder for details
